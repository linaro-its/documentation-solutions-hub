org commands
============

``spire org create``
--------------------

Create a new organisation.

Flags:

* ``--name`` (required)

  The name of the organisation to create.

The flag ``--json`` can be used to return the information in a JSON structure.

``spire org list``
------------------

List the organisations that the authorization token grants access to. The flag ``--json`` can be used to return the information in a JSON structure.
